# MitraSkill (मित्रस्किल)
### AI-Enabled Career Counselling & Family Decision-Support Platform for Vocational Education
**Smart India Hackathon (SIH) 2026**  
**Problem Statement ID:** 26241  
**Organization:** Ministry of Skill Development and Entrepreneurship (MSDE)

---

## Project Overview

MitraSkill bridges the generational perception gap in vocational education across Indian households. By pairing a synchronous dyadic co-counselling engine with verified administrative data (DGT Tracer Audits, NCVET registries) and National Credit Framework (NCrF) degree mobility pathways, the platform resolves parental hesitation regarding social prestige, wages, and workplace safety.

## Tech Stack

- **Frontend Framework:** React 19 + TypeScript + Vite
- **Routing and SSR:** TanStack Start and TanStack Router
- **Styling:** Tailwind CSS + Radix UI Primitives + Lucide Icons
- **Animation:** Framer Motion
- **State Management:** React Context API

## Getting Started

### Prerequisites

- Node.js v18 or higher
- npm or pnpm

### Installation

```bash
npm install
npm run dev
```

The development server runs at `http://localhost:8080`.

### Production Build

```bash
npm run build
npm run preview
```

TanStack Start writes the production output to `.output/`.

### Quality Checks

```bash
npm run lint
npm test
```
